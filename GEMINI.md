# GEMINI.md

This project's shared AI-agent context (what KhetGPT is, the repo layout, fixed decisions, conventions and commands) lives in **`AGENTS.md`** at the repo root. Read that file first.

Antigravity and Gemini CLI load `GEMINI.md` by default, which is why this pointer file exists. If you would rather have Antigravity read `AGENTS.md` directly, set `context.fileName` to `AGENTS.md` (or `["AGENTS.md", "GEMINI.md"]`) in your Antigravity/Gemini CLI settings.
